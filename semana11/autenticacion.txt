El login es el proceso mediante el cual un usuario ingresa a una aplicación utilizando sus credenciales para verificar su identidad. Esto permite controlar quién puede acceder a determinadas funciones del sistema. Algunas rutas deben estar protegidas porque contienen información privada o permiten realizar acciones importantes, como crear, modificar o eliminar registros. De esta manera se evita el acceso no autorizado. Además, nunca deben exponerse públicamente contraseñas, documentos de identidad, teléfonos, direcciones, tokens, claves de API ni otros datos sensibles de los usuarios o de la comunidad.
